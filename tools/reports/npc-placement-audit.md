# NPC placement audit: quest NPCs and objects against the official servers

Generated by `python tools/npc_placement_audit.py`; do not edit by hand. Refresh the official samples with
`python tools/official_npc_placements.py` after recording new captures (server->client only), then run the audit.

## Inputs

- 898 available quests (above-cap / unavailable ones skipped) naming 1542 NPCs / objects on 7 maps.
- Placement checked for talk NPCs (giver, finisher, AskNpc, CloseNpc) and UseEnvObj objects: 807 (id, map) pairs, 1860 server spawns. Kill targets are only checked for a spawn on the right map (monsters wander).
- Official samples: 1218 NPC spawns and 327 objects from 9 captures, on maps 1010, 101022, 101042, 210008, 210011, 310001, 310002, 310004, 310010, 310013, 310016, 310024, 310045, 600031, 840019.
- **188 of 1860 quest spawns have an official sample**; the other 1672 are unknown, not correct. A quest-gated NPC only appears while its step is open, so a capture of the map without the quest has no sample of it either.
- Server position = the MapData row (the client's own table), yaw unchanged; standing NPCs are grounded at runtime when the floor is within 100 (official appears sit ~20 below the MapData Z). Rows marked OURS come from the quest supplement and have no client row.
- Class: no quest in quests.json is gated by class (QuestClassReward only changes rewards), so placement does not differ by class; race and level band are below.
- Terrain height: not in this report (needs research/local/terrain, see `--terrain`).
